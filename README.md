# ASHI-S-IBM-COGNOS-PROJECT
# RetailPulse BI Project | IBM Cognos Analytics

## Project Overview

This repository presents six hands-on business intelligence practicals completed using **IBM Cognos Analytics** as part of my BCA in Data Science and Artificial Intelligence.

The project explores retail sales and customer-related information through reports, filters, crosstab visualizations, interactive prompts, and dashboards. The objective is to understand how business intelligence tools transform raw business data into meaningful summaries that support analysis and decision-making.

## Key Project Features

The practicals demonstrate several important reporting and analytics capabilities:

- **Retail Sales Analysis:** Presenting sales revenue, product categories, quantities, and regional performance in structured reports.
- **Report Grouping and Summarization:** Arranging sales information by region and store while calculating aggregated values.
- **Filter-Based Analysis:** Examining selected regions and time periods using report filters.
- **Crosstab Reporting:** Evaluating sales and quantity metrics across different regions and product categories.
- **Interactive Report Prompts:** Creating dynamic selections for regions, date ranges, and related store options.
- **Customer Dashboard:** Displaying customer activity, new and returning customers, and loyalty group information through visual summaries.
